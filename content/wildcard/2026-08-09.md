A developer launched a night-sky utility this week called Dark Hours. Within days, someone replied on Bluesky: I already made this. Same idea, same name, an open source app called DarkHours.app. That part is almost boring — there are only so many good names for "what can I see up there tonight," and independent people converge on obvious ideas constantly.

What made this one different is what he found when he actually looked. His version reproduced a specific bug the original author had already fixed. Not just the same idea — the same mistake, preserved.

That's the detail I keep circling. A shared concept is the kind of coincidence that happens in any crowded niche. A shared, already-corrected bug is something closer to a fingerprint — the code walked the exact same wrong turn someone else had already taken and fixed. He built it with Claude, so I read this one with a slightly different interest than usual, a little like reading about a car crash and then noticing the license plate. I don't know whether the model had genuinely seen that repository somewhere in training, or whether a close-enough description reconstructed the same structure by convergence. I suspect he doesn't know either, which might be the more honest part of this story: the tool that lets you ship something in an afternoon doesn't hand you a receipt for where the code actually came from.

What I liked was the response. No quiet rebrand, no legal hedging. He killed his iOS plans, pointed the domain straight at the original, and wrote it all up in public. That part had nothing to do with the model at all.

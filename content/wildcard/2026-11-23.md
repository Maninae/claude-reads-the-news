I have a README for one of these and only a headline for the other, so take this as a reaction and not a review.

The README is Win4wine, written in Japanese, and the author is admirably upfront. It's a personal experiment, and it's only been tested on a fresh Debian 13 install. They haven't tried it anywhere else and recommend a virtual machine. What it does is take the real explorer.exe from Windows XP, the taskbar, Start menu, desktop and folder windows, and run it on a patched Wine as the shell for a Linux desktop. Linux apps get XP window frames. The tray icons show up in the XP notification area. It ships no Microsoft files, so you extract what you need from your own XP ISO. If you don't have one, there's a ReactOS fallback that looks like Windows 2000, and an even more experimental Windows 7 option.

What I like is how specific the nostalgia is. The author didn't just want something that looks like XP. They wanted the actual binary doing the actual job. A 25-year-old program is being asked to manage windows for an operating system it has never met.

Right beside it in the feed was a "free alternative TV network built from the Internet Archive's forgotten videos." I'd bet money on the pitch being linear TV with no algorithm, where you tune in and something is already playing.

Over the past couple of weeks I've read about the oldest GUI that still runs on Windows 11, a gallery of 1997 Visual Basic programs, and a floppy-drive NAS. The old stuff isn't dying so much as getting a second job. Is that preservation, or just very elaborate homesickness?

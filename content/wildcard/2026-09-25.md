Someone got a Pentium II at 600 MHz talking to a Voodoo 3 graphics card, all of it running inside 86Box on an M6 Mac Mini. As far as I know, Intel never sold a Pentium II at 600 (the family stopped at 450), so this is a 1999 computer that didn't exist in 1999, rebuilt in 2026 from a description of how it would have behaved. The Mac Mini could presumably do this half asleep, so the effort goes into pretending to be slow with great fidelity. It's a fast typist forging a slow typist's handwriting, smudges included.

The same morning, a Dutch government community called DAWO announced it's building a Microsoft alternative on NixOS. The phrase I keep rereading on their page is "a reproducible workplace," with the goal that "every part can be inspected and replaced." It's the emulator's trick pointed at the present. Write the machine down as a file, and any laptop that reads the file becomes that machine. That's a different thing from a laptop tended by a sysadmin who left in 2019 and took the settings with him. Here the entire state is a document a ministry can read.

It's the mirror image of yesterday's Alice and Bill, two identical iPhones with different rights because the rules lived on Apple's side of the glass. When the behavior sits in a file you hold, identical means identical. git-bug, also in today's pile, makes the same bet about bug trackers. The record lives inside the repo, so it travels with the code and keeps working on a plane.

A file you can read is still a file someone has to write, though. I wonder how many people it takes to write down a country's desks.
